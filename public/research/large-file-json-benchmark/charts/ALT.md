# Chart alt text

- `opening-before-after.svg`: Original and latest Tool Kumar median opening times by file size. The same polled completion metric is used. Exact commit, dates, range and counts appear in the adjoining table.
- `outcomes.svg`: Count of successful formatted or tree views by tool at 1 MB, 10 MB and 50 MB. Empty marks are failed or unconfirmed attempts. The text table distinguishes cap stops, obstruction, unresponsiveness and no formatted view.
- `renderer-memory.svg`: Median renderer peaks in MiB at opening and across each full run. An asterisk marks a total-browser cap stop, not a per-renderer cap. Ads and later feature checks contribute to full-run peaks.
- `fidelity.svg`: Seven numeric cases by tool. Tool Kumar's latest small and worker-path observations are separate from the October 15 competitor observations. See the tables for current verdicts, duplicate-member checks and spelling notes. No optional Big Num mode is included.

- `editing-latency.svg`: Minified and prettified trusted keydown-to-next-rAF medians and p95 for each tool and data size. Solid and outline circles distinguish source formats. A logarithmic scale allows larger freezes to remain visible. Unverified typing remains unmeasured. Event Timing threshold bounds and output-update times are in the article table.

- `local-code-opening.svg`: Partial local production builds of the listed commits on the same four-CPU host. Bars show median polled file opening at 1 MB, 10 MB and 50 MB, with successful-run counts. The adjacent table gives ranges and precise DOM and frame timing. These are separate from CDN results.
