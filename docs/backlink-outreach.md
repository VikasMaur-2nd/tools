## Submission copy

**Name:** Tool Kumar

**Short description:** A free, private JSON viewer and formatter that runs in your browser and works offline.

**Long description:** Tool Kumar formats, validates, repairs, minifies and compares JSON without uploading documents for processing. It includes tree and table views, search, JSON paths, lossless large-number handling and export tools. The resource library has a standards-based JSON syntax reference and downloadable example files for APIs, configuration and tests. No account is required.

**Category:** Developer tools / JSON tools / web development

**Suggested editorial link text:** Tool Kumar JSON viewer, JSON syntax reference, or JSON examples.

**Suggested editorial destinations:** Use the homepage for a tool directory, the reference for a syntax article, and the examples page for a tutorial or fixture collection.
